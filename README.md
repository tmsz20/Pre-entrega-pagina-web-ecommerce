# Proyecto Final E-commerce: 1337tech

Este es el proyecto final del curso de desarrollo web. Consiste en la creación de un sitio web de e-commerce dinámico e interactivo enfocado en la venta de productos de tecnología, periféricos y hardware.

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio web (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Diseño responsivo, utilizando **Flexbox** y **CSS Grid** para la organización de los elementos.
- **Bootstrap 5:** Implementación de componentes interactivos y responsive (ej. UI del carrito de compras).
- **JavaScript (Vanilla JS):** Lógica del carrito de compras, manipulación del DOM y validación de formularios.
- **Fetch API:** Consumo de datos desde una API local (`productos.json`) para renderizar los productos dinámicamente.
- **LocalStorage:** Persistencia de datos del carrito de compras en el navegador del usuario.

## Características Principales

- **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y monitores grandes.
- **Catálogo Dinámico:** Productos cargados vía Fetch API.
- **Carrito de Compras:** Posibilidad de añadir, eliminar y modificar cantidades de los productos, con guardado persistente.
- **Formulario de Contacto:** Integrado con Formspree para envío de emails funcionales.
- **Accesibilidad y SEO:** Metaetiquetas descriptivas, atributos `alt` en imágenes y buena estructura de encabezados.

## Instalación y Ejecución Local

1. Clonar este repositorio:
   ```bash
   git clone https://github.com/tmsz20/Pre-entrega-pagina-web-ecommerce.git
   ```
2. Abrir la carpeta del proyecto.
3. Para probar la Fetch API localmente, se recomienda utilizar una extensión como "Live Server" en VS Code.
